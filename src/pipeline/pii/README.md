## Considered PII Types

The following PII types were defined for detection:

- email  
- phone  
- ip  

## Detection Strategy

PII detection is based on a hybrid approach that combines structured detection using regular expressions (regex) and contextual validation using the DataFog model.

### Regex-based Detection

Regular expressions are used to identify clearly defined structured patterns.

- Email addresses are detected exclusively using regex because they follow a highly structured and stable format.
- Phone numbers and IPv4 addresses are initially detected using regex-generated candidates.

### DataFog-based Detection

DataFog is employed as a contextual validation mechanism for phone numbers and IP addresses, configured with the following engine:

```python
DATAFOG_ENGINE = "smart"
```

This method enables contextual verification of candidate detections generated by regex.

## Decision Rule

For `phone` and `ip`, a detection is considered valid only if:

- both methods identify the same PII type  
- the corresponding spans overlap within the text  

Formally:

```python
if regex_item["type"] == datafog_item["type"] and spans_overlap(regex_item, datafog_item):
    confirmed.append(regex_item)
```

Under this criterion:

- regex acts as a candidate generator  
- DataFog acts as a contextual validator  
- only mutually confirmed detections are retained  

For `email`, detections generated by regex are accepted directly without contextual validation.

## Label Normalization

Since DataFog may return heterogeneous labels, a normalization process is applied to map them to the predefined PII types.

Mappings include:

- email, mail → email  
- phone, telephone → phone  
- ip, ip_address, ipv4 → ip  

Labels that do not match the defined categories are discarded.

## Additional Validations

To reduce false positives, specific validation rules are applied:

- Email: must conform to a valid full email format  
- IP: must be a valid IPv4 address (four numeric blocks in the range 0–255)  
- Phone: must contain between 8 and 15 digits; patterns resembling dates or numeric ranges are excluded
